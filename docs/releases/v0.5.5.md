# Muse Desktop v0.5.5 — Friend-testing preview

A small Windows desktop cat with up to two daily tasks, a 50-minute focus timer and optional session notes.

## Download

- **Muse-Desktop-Setup-0.5.5-x64.exe** — recommended installer; creates Desktop and Start Menu shortcuts.
- **Muse-Desktop-Portable-0.5.5-x64.exe** — run without an installation wizard.
- **SHA256SUMS.txt** — checksums of the two executables.

Choose an EXE under **Assets**. The Source code archives are for developers. For daily use, launch **Muse Desktop**, not the Setup file again.

## Before you try it

- Windows x64 only; no Node.js, PowerShell or GitHub account needed for the release downloads.
- **Unsigned preview:** SmartScreen may show an unrecognized-app / unknown-publisher warning. Confirm the repository and filename, and decide whether to trust this test build. Do not disable Windows protection.
- Personal task use currently requires your own Notion workspace, read-only integration, Tasks data source and Muse State row. Never share the creator's credentials.
- A task must be selected before the focus timer can start. Local task entry and task-free focus are not available yet.
- **Chat → document → Notion → Muse has not been validated end to end.** A document update alone will not update the app; no generic document-to-Notion automation is bundled.

## What changed

- Electron updated from 35.7.5 to 45.2.3.
- Vulnerable build-tool dependency patched with a targeted minimatch override.
- Complete npm dependency audit reported 0 advisories at build time.
- Added automated packaged-Windows tests for startup, isolated renderer, bridge authentication, panel expansion, task selection, timer actions, restart persistence and Settings.

## Test scope

These exact executables come from [successful Windows build 42337004089](https://github.com/yl14982-cloud/muse-desktop/actions/runs/42337004089), source commit `b9ed47a2f18f61b96cbcf02d2feb5998ef4f8491`. Automated tests launch the unpacked application. Installer wizard behavior, existing-profile migration, live Notion access and the full conversation route still need manual testing. A clean dependency audit is not a guarantee of complete security.
