# Muse Desktop v0.6.0 — Local tasks + optional Notion

One desktop cat, two ways to use it. **Install → Add a task → Choose it for Today → Start focusing.** No account or Notion setup is required for the local board.

## Download under Assets

- **Muse-Desktop-Setup-0.6.0-x64.exe** — recommended Windows x64 installer.
- **Muse-Desktop-Portable-0.6.0-x64.exe** — no installation wizard.
- **SHA256SUMS.txt** — executable checksums.

Use the installed **Muse Desktop** shortcut for daily launches; the Setup file starts the installer again.

## New in v0.6.0

- Add local tasks directly in Muse and keep them on your computer.
- Choose up to two tasks for Today, complete them and reopen them.
- Choose the cat's mood manually without connecting any service.
- Keep the 50-minute timer, pause / resume, notes and saved session history.
- Optional Notion settings are collapsed until needed. Local and imported tasks can coexist.
- Disable or disconnect sync while keeping local tasks and focus history.
- Notion refreshes do not overwrite local task data or manually selected mood.
- Preserve focus records and migrate cached selected Notion tasks from the earlier version when available.

## Optional chat-driven workflow

With separately authorized tools, an assistant can update your own Notion Tasks data source or State row. Muse reads those fields on Sync now or its regular refresh; you choose which imported tasks belong in Today. Imported tasks are read-only in Muse, so update their completion in Notion.

Assistant-to-Notion test writing and readback have been demonstrated in the creator's workspace. The desktop connection was incomplete at the last live test; the full conversation-to-Notion-to-Muse chain and cross-account setup are still under validation. Muse does not monitor all chats or automatically turn an arbitrary document into a Notion update.

## Validation

Release publication requires a successful Windows build with dependency audit, source checks, local task / migration tests, simulated Notion merge / failure / cancellation tests, and packaged Windows UI tests for adding, selecting, completing and reopening tasks, timer actions, manual mood and restart persistence. Automated Windows tests launch the unpacked application, not the installer wizard. They use no personal integration credentials.

## Before trying it

This is an **unsigned pre-release**. Windows can display SmartScreen or unknown-publisher warnings. Verify the source and decide whether to trust this preview; do not disable Windows protection. Real-profile upgrades and interactive installer behavior still need manual feedback. Back up your user-data folder before upgrading, and quit the previous Muse process. No automatic updater or code-signing identity is configured.
